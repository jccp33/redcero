# Continuidad de Red Cero

Antes de iniciar trabajo en este proyecto, leer:

- `docs/prompt-maestro.md`: requisitos y restricciones del proyecto.
- `docs/estilo.md`: identidad visual y experiencia de juego sin conocimientos previos.
- `docs/siguiente-sesion.md`: estado y tareas pendientes guardadas a petición del usuario.
- `README.md`: arranque, pruebas y limitaciones del entorno.

Verificar el estado real de archivos, Git, servicios y base de datos antes de actuar; las notas de continuidad pueden quedar desactualizadas. Mantener las partidas y los cambios existentes. No versionar secretos ni respaldos sensibles.
